ON` **não é respeitado de forma confiável** por chamadas subsequentes `tx.<model>.create()`/`tx.$executeRaw` dentro do mesmo `$transaction()` interativo — mesmo dentro de uma única transação lógica, o SQL Server ainda reporta `IDENTITY_INSERT is set to OFF`.
